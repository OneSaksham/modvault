# Security Policy

## Supported Versions

Only the latest stable release of ModVault receives security updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0.0 | No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in ModVault, please report it responsibly:
- Do not create a public GitHub issue.
- Contact the creator directly via [GitHub Profile](https://github.com/saksham-kumar1621) or email.
- Include detailed steps to reproduce the issue and affected operating systems.

We aim to acknowledge reports within 48 hours and release patches promptly.
