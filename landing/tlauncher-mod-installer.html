Why TLauncher Always Crashes With Manual Mods

If you have ever dragged a .jar file into your folder and Minecraft refused to launch with "Exit Code 1", here is the technical reason why:

folder_off

The Dual Path Trap

Standard TLauncher uses %APPDATA%\.minecraft\mods. But TL Legacy uses %APPDATA%\.tlauncher\legacy\Minecraft\game\mods. Putting mods in the wrong folder causes Minecraft to ignore them completely.

link_off

Missing Secondary Libraries

Modern mods rely on secondary APIs. For example, Iris Shaders requires Sodium, Indium, and Cloth Config. If even one library is missing or has a mismatched version build, the JVM crashes instantly before reaching the title screen.

sync_problem

Loader Cross-Contamination

TLauncher allows creating multiple version profiles (Fabric 1.20, Forge 1.20, NeoForge). But by default, they all share one single mods folder! When a Forge mod is loaded by Fabric, it causes fatal classloader exceptions.
