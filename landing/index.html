Questions Answered

Frequently Asked Questions

Everything you need to know about ModVault, safety, and compatibility.

Does ModVault work with TL Legacy, TLauncher, and custom launchers? expand_more
Yes, 100%. ModVault features zero-hardcoded path scanning. It checks the standard AppData locations for TL Legacy (.tlauncher/legacy/Minecraft/game), standard TLauncher, Prism Launcher, Modrinth App, CurseForge, and Vanilla Minecraft. If your game directory is on another hard drive, you can easily select it with one click.
Will using ModVault or its optimization mods get me banned on servers? expand_more
No. ModVault only installs client-side optimization and visual quality-of-life mods (such as Sodium, Lithium, FerriteCore, Iris, and AppleSkin). These mods are fully compliant with Hypixel, PvP servers, and official multiplayer server rules. They do not alter game mechanics or provide any unfair cheats.
How does recursive dependency resolution prevent Game Crash Exit Code 1? expand_more
When you download a mod like Iris Shaders or Sodium, it requires secondary libraries like Fabric API, Indium, or Cloth Config. If you miss one, Minecraft triggers Exit Code 1 on launch. ModVault queries Modrinth's official v2 API graph, identifies all required libraries for your exact game version and loader, and downloads them together in sequence.
Do I need to install Java manually before running ModVault? expand_more
No. ModVault runs as a standalone Windows executable. It automatically uses the bundled Java JRE already provided by your Minecraft launcher (e.g. Java 17 for 1.18 - 1.20.4, or Java 21 for 1.20.5+), so you do not need to configure environment variables or JDKs manually.
Is ModVault completely free, open-source, and safe? expand_more
Yes, 100%. ModVault is open-source under the MIT license on GitHub by Saksham. It contains zero adware, zero token grabbers, zero crypto-miners, and zero telemetry tracking. All downloads are fetched directly from Modrinth's verified CDN.
Can I keep my existing worlds and mods safely? expand_more
Absolutely. ModVault only manages the mods/ folder and does not touch your saves/ or world data. Additionally, ModVault supports non-destructive disabling: if you want to turn off a mod, it renames it to .jar.disabled without deleting your files.
